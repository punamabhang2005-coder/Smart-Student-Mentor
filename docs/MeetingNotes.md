 # Week 3 Progress

Date: 29 July 2026

## Meeting Discussion

The project meeting was conducted on Wednesday at 7:00 PM.

The discussion focused on understanding how the existing essay data will be used and how the backend will generate a review for a newly submitted essay.

## Main Points to Work On

### 1. Using Existing Essay Data

We discussed a scenario with around 50 existing student essays and their mentor reviews.

The plan is to use the existing data as reference data for the Smart Student Monitor. Each student's previous essays and reviews will be maintained as their individual history.

When a student submits a new essay, the system will use that student's previous essay history and reviews to help generate a personalized review.

This approach is still being studied and will be refined during development.

### 2. What Happens When a New Essay Is Submitted

We discussed the complete process that should happen after a student submits a new essay.

Initial workflow:

Student submits essay  
↓  
Backend receives the essay  
↓  
Identify the student  
↓  
Retrieve the student's previous essays and reviews  
↓  
Analyze the new essay with the previous history  
↓  
Generate a personalized review  
↓  
Save the new essay and review  
↓  
Use the new data as part of the student's history for future submissions

The exact AI algorithm and backend implementation are still under discussion.

## Summary

The main focus for the next meeting is to finalize:

1. How the existing 50 essay data points will be used in the project.
2. Exactly what happens in the backend when a new essay is submitted and which algorithm will be used to generate the review.

## Current Status

The backend design is currently in the planning stage. No final algorithm has been selected yet. The design will be updated after further discussion and testing.
